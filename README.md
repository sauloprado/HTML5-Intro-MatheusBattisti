## Sobre

Exercícios do curso **HTML5 Fundamental — o seu primeiro passo na web** (Matheus Battisti), em sequência numerada: da estrutura básica de uma página até formulários completos.

## O que foi praticado

| Arquivo | Conceito |
| --- | --- |
| `1_primeira_estratura.html` · `2_estrtura_html.html` | Estrutura de um documento HTML |
| `3_headings.html` | Títulos (`h1` a `h6`) |
| `4_paragrafo.html` | Parágrafos |
| `5_Links..html` | Links |
| `6_formularios.html` | Formulário completo |
| `7_jogo.html` · `8_jogo.html` · `9_jogo.html` | Páginas de prática (boliche, tênis de mesa e corrida 3D) |

## Como visualizar

```bash
git clone https://github.com/sauloprado/HTML5-Intro-MatheusBattisti.git
```

Abra os arquivos `.html` no navegador, na ordem numérica.
